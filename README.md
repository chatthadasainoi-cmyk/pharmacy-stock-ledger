# สมุดคลังยา

เว็บแอปตรวจวันหมดอายุสำหรับร้านยา ใช้แทนการกรองสีในไฟล์ Excel "แบบบันทึกการรับสินค้า และตรวจสอบวันหมดอายุ" ช่วยแยกสีล็อตตามวันหมดอายุ และแจ้งเตือนเมื่อถึงกำหนดทำคืนสินค้า

**ใช้งานจริง:** https://chatthadasainoi-cmyk.github.io/pharmacy-stock-ledger/

## ทำอะไรได้

- **นำเข้า Excel** (.xlsx / .xls / .csv)
  - ระบบจับคอลัมน์ Barcode, SKU, Description, Amount, Lot no., EXP Date, วันที่รับ, Vendor Name, Class และเงื่อนไขทำคืนให้อัตโนมัติ แก้ได้ถ้าจับผิด
  - ใช้ได้ทั้งไฟล์รับสินค้า (Credit / Consignment) และไฟล์ Build Update ที่ไม่มี Lot
  - นำเข้าไฟล์เดิมซ้ำได้ แถวที่เคยนำเข้าแล้วจะถูกข้าม
- **แยกสีตามวันหมดอายุ** เหมือนไอคอนสีใน Excel (เกณฑ์แก้ได้ในหน้าตั้งค่า)

  | สี | เงื่อนไข (ค่าเริ่มต้น) |
  |---|---|
  | เขียว | เหลือมากกว่า 7 เดือน |
  | เหลือง | เหลือไม่เกิน 7 เดือน |
  | ดำ | เหลือไม่เกิน 5 เดือน |
  | แดง | เหลือไม่เกิน 4 เดือน |
  | หมดอายุ | เลยวันหมดอายุแล้ว |

  มีสถานะ **OK / Nearly Expired** (เหลือน้อยกว่า 250 วัน) ตามสูตรในไฟล์เดิมด้วย
- **กำหนดทำคืนรายล็อต**
  - อ่านจากข้อความเงื่อนไข เช่น "ทำคืนก่อนหมดอายุ 7 เดือน" หรือ "ทำคืนหมดอายุแล้ว"
  - สินค้าที่ไม่มีเงื่อนไขใช้ค่าเริ่มต้นของร้าน
- **แจ้งเตือน**
  - หน้าแรกรวมล็อตที่ถึงกำหนดทำคืน และที่จะถึงกำหนดภายใน 30 วัน
  - มีตัวเลขบนเมนูและบนแท็บเบราว์เซอร์
  - เปิดแจ้งเตือนบนเครื่องได้ จะเด้งวันละครั้งเมื่อเปิดแอป
- **ปิดล็อต:** กด "ทำคืนแล้ว" / "ไม่มีของแล้ว" / "นับสต็อก" รายการจะหายจากแจ้งเตือนแต่ประวัติยังอยู่
- **รับสินค้าด้วยการสแกน**
  - ใช้เครื่องสแกน USB, กล้อง หรือถ่ายรูปก็ได้ รองรับ EAN-13 และ GS1 DataMatrix (อ่าน LOT/EXP ให้เอง)
  - ระบบบอกสีและกำหนดทำคืนก่อนบันทึก
- **ส่งออก Excel:** ได้ตารางวันหมดอายุตามตัวกรองที่เลือก
- **คู่มือในแอป:** ทัวร์แนะนำหน้าจอ และขั้นเริ่มต้นใช้งาน 3 ขั้น

## ข้อจำกัดของการแจ้งเตือน

- **เด้งเฉพาะตอนเปิดแอป:** เตือนเมื่อเปิดแอปหรือเปิดค้างไว้เท่านั้น ถ้าจะให้เด้งตอนปิดแอปต้องมีเซิร์ฟเวอร์ส่ง push (Firebase Cloud Functions ต้องใช้แพ็กเกจ Blaze)
- **บน iPhone:** ต้องเพิ่มแอปไปยังหน้าจอโฮม แล้วเปิดจากไอคอนก่อน จึงจะใช้การแจ้งเตือนได้

## โครงสร้างไฟล์

```
index.html            โครงหน้า
style.css             หน้าตา (โทนสว่าง/มืด)
config.js             ค่า Firebase ของร้าน (ถ้าเป็น null จะเก็บข้อมูลในเบราว์เซอร์)
js/core.js            ข้อมูล การเก็บข้อมูล กฎสีและกำหนดทำคืน การอ่านบาร์โค้ด
js/views.js           หน้าแจ้งเตือน วันหมดอายุ รับสินค้า สินค้า ประวัติ ตั้งค่า
js/import.js          นำเข้า/ส่งออก Excel
js/ui.js              ลิ้นชักสินค้า หน้าต่างย่อย การสแกน กล้อง การแจ้งเตือน
js/app.js             ปุ่มต่าง ๆ คู่มือ และการเริ่มแอป
sw.js                 service worker สำหรับการแจ้งเตือนบน Android
firestore.rules       กฎสิทธิ์ของ Firestore
sample/               ข้อมูลตัวอย่าง (สมมติทั้งหมด) และไฟล์ Excel ตัวอย่าง
tools/make-sample.mjs สร้างข้อมูลตัวอย่าง
```

## ข้อมูลใน Firestore

- `shops/main/products/<id>`: ชื่อ, SKU, บาร์โค้ด, Vendor, Class, เงื่อนไขทำคืน (`returnCond`, `returnMonths`), ล็อต (`lots.<id> = {lot, exp}`)
- `shops/main/moves/<YYYY-MM-DD>`: รายการของวันนั้นในรูป `entries.<id>`
  - มี `type` (receive / return / clear / adjust), `kind` (credit / consignment), `pid`, `lotId`, `qty` และ `note`
  - ยอดคงเหลือของแต่ละล็อตคำนวณจากรายการเหล่านี้
- `shops/main/meta/settings`: เกณฑ์สี และจำนวนวันที่ใช้เตือน

## ตั้งค่า Firebase (ทำครั้งเดียว)

1. **Authentication:** เปิดวิธีล็อกอิน Google แล้วเพิ่มโดเมนเว็บใน Authorized domains
2. **Firestore:** สร้างฐานข้อมูลแบบ Standard ชื่อ `(default)` แล้ววางเนื้อหา `firestore.rules` ในแท็บ Rules
3. **config.js:** วางค่า `firebaseConfig` ของเว็บแอป

ค่าใน `config.js` เป็นค่าสาธารณะของเว็บแอป ไม่ใช่รหัสลับ สิทธิ์เข้าถึงข้อมูลกำหนดด้วย Rules
